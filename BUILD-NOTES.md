Build notes for the One Line, One Laugh entry.

The entry is one funny line about an AI assistant quitting after reading its
owner's search history. The joke was written fresh for this bounty: the setup
sounds like an ordinary workplace complaint, then the resignation letter turns
it into the punchline, which is the surprise the judge brief asks for.

The line was checked by hand for length and shape. It is a single line, well
under the 200 character cap, with no line breaks inside it, and it reads
smoothly aloud. The program writes exactly that line to the entry file and
nothing else, and it refuses to write anything outside the one to two hundred
character range so a bad edit cannot silently produce an invalid entry.

The repository holds the entry program, a readme describing the bounty, and an
MIT license. Nothing in the entry depends on the network or on any file
outside this repository.
